---
title: "Create Category"
api: "POST /v1/categories"
description: "Create a new category or return an existing one with the same name."
---

Creates a new category. If a category with the same name already exists for the user, the existing category is returned instead of creating a duplicate.

## Body parameters

<ParamField body="name" type="string" required>
  Category name.
</ParamField>

<ParamField body="color" type="string">
  Hex color code (e.g., `#3B82F6`).
</ParamField>

## Response

<ResponseField name="data" type="object">
  The created or existing category object.
</ResponseField>

<RequestExample>
```bash cURL
curl -X POST https://api.nenyahq.com/functions/v1/api/v1/categories \
  -H "Authorization: Bearer nenya_sk_your_key_here" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Backend",
    "color": "#F59E0B"
  }'
```
</RequestExample>

<ResponseExample>
```json 201
{
  "data": {
    "id": "880e8400-e29b-41d4-a716-446655440002",
    "name": "Backend",
    "color": "#F59E0B",
    "created_at": "2025-01-15T10:30:00Z"
  }
}
```

```json 400
{
  "error": "name is required"
}
```
</ResponseExample>
