The [Model Context Protocol (MCP)](https://modelcontextprotocol.io/) is an open standard that lets AI assistants interact with external tools and data sources. The Nenya MCP server implements this protocol, giving AI assistants like Claude direct access to your task management system.

## Architecture

The MCP server runs as a local process on your machine. It communicates with the AI assistant over **stdio** using JSON-RPC, and authenticates to the Nenya API using OAuth 2.0 with PKCE.

```
┌─────────────┐     stdio/JSON-RPC     ┌──────────────┐      HTTPS       ┌─────────────┐
│  AI Client   │ ◄──────────────────► │  MCP Server   │ ◄──────────────► │  Nenya API   │
│ (Claude Code)│                       │ (local process)│                  │  (Supabase)  │
└─────────────┘                       └──────────────┘                  └─────────────┘
```

Your credentials are stored locally and never pass through the AI assistant.

## Available tools

The server exposes 9 tools:

| Tool | Description |
| ---- | ----------- |
| `list_tasks` | List tasks with filters for status, priority, and category |
| `get_task` | Get a single task by ID |
| `search_tasks` | Semantic search across your tasks |
| `create_task` | Create a new task from text |
| `update_task` | Update an existing task |
| `complete_task` | Mark a task as completed or reopen it |
| `delete_task` | Permanently delete a task |
| `list_categories` | List all categories with task counts |
| `get_stats` | Get productivity statistics |
