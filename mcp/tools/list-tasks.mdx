---
title: "list_tasks"
description: "List your tasks with optional filters for status, priority, and category."
---

Retrieves a list of tasks, optionally filtered by status, priority, or category. Returns tasks ordered by position.

## Parameters

<ParamField body="status" type="string" default="active">
  Filter by task status. Options: `active`, `completed`, `all`.
</ParamField>

<ParamField body="priority" type="string">
  Filter by priority level. Options: `high`, `medium`, `low`.
</ParamField>

<ParamField body="category" type="string">
  Filter by category name (case-insensitive).
</ParamField>

<ParamField body="limit" type="number" default="50">
  Maximum number of tasks to return.
</ParamField>

## Example

```
You: Show me my high-priority active tasks

Claude uses list_tasks with:
  status: "active"
  priority: "high"
```
