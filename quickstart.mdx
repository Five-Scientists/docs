## Choose your integration

Pick the approach that fits your workflow.

<Tabs>
  <Tab title="Claude Code (MCP)">
    The fastest way to get started. Let Claude manage your tasks directly.

    ### 1. Install the MCP server

    ```bash
    npx @nenyahq/mcp-server install
    ```

    This adds Nenya to your Claude Code MCP configuration automatically.

    ### 2. Authenticate

    The first time Claude uses a Nenya tool, your browser will open to authorize the connection. Sign in with your Nenya account and approve access.

    ### 3. Start using it

    Ask Claude things like:

    - *"Add a task: Review the PR for the auth refactor"*
    - *"Show me my high-priority tasks"*
    - *"Mark the deploy task as complete"*

    <Tip>See the full list of available tools in the [MCP Tools Reference](/mcp/tools/list-tasks).</Tip>
  </Tab>

  <Tab title="REST API">
    Use the REST API to integrate Nenya into any application.

    ### 1. Get an API key

    Generate an API key from the [Nenya app](https://app.nenyahq.com) under **Settings > API Keys**. Keys use the `nenya_sk_` prefix.

    ### 2. Make your first request

    ```bash
    curl https://api.nenyahq.com/functions/v1/api/v1/tasks \
      -H "Authorization: Bearer nenya_sk_your_key_here"
    ```

    ### 3. Create a task

    ```bash
    curl -X POST https://api.nenyahq.com/functions/v1/api/v1/tasks \
      -H "Authorization: Bearer nenya_sk_your_key_here" \
      -H "Content-Type: application/json" \
      -d '{"raw_text": "Review the PR for the auth refactor"}'
    ```

    <Tip>See the full [API Reference](/api-reference/introduction) for all available endpoints.</Tip>
  </Tab>
</Tabs>
